PyStart — learn Python in your browser

PyStart is a free, interactive Python course. It runs real Python in your browser (via Pyodide / WebAssembly) — there is nothing to install and no account to create, and after the first visit it works offline. Every lesson has diagrams, editable examples you can run, and auto-graded exercises on a difficulty ramp: the grader accepts any working answer, then nudges you toward cleaner, more idiomatic code.

The course is 61 lessons and 406 exercises across 14 sections, plus 5 checkpoint projects:

  • Learn the basics — syntax, variables, operators, strings, conditionals, loops, lists / tuples / sets, dictionaries, type casting, functions, exceptions, comments and type annotations
  • Data structures & algorithms — arrays and linked lists, hashmaps, stacks / queues / heaps, binary search trees, recursion, sorting
  • Modules — import, lambdas, decorators, iterators, regular expressions, variable scope
  • Package managers & idioms — pip / Poetry / uv, comprehensions, generators, context managers, pyproject.toml, programming paradigms
  • Object-oriented programming — classes, methods, inheritance, encapsulation
  • Environments — virtualenv, Pipenv, pyenv
  • Concurrency — the GIL, threading, multiprocessing, asyncio
  • Static typing — typing, mypy, pyright, pyre, Pydantic
  • Tooling — black, yapf, ruff, Sphinx, file handling
  • Testing — unittest, doctest, pytest, tox
  • Web frameworks — Flask, Django, FastAPI, and async frameworks
  • More Python — structural pattern matching, a standard-library tour

Lesson material is adapted from Harvard's CS50's Introduction to Programming with Python and the official Python documentation. The course opens instantly — no sign-up required.
